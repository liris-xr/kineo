# Sequences excluded from the CMU Panoptic TEMPO protocol.

# data corruption". Earlier work sharing the same five-camera split does keep
# it: it is the tenth entry of VoxelPose's TRAIN_LIST, and VTP inherits that
# list.
#
# `TEMPO_TRAIN_SEQUENCES` already leaves it out, so it is never downloaded
# rather than downloaded and then dropped. This list is what keeps it out of
# everything downstream, including a directory the panoptic-toolbox populated.
#
# Kept in the repository rather than read from the download so preprocessing
# is reproducible without re-fetching anything.
